# Salary Cat · 工资电子猫

Windows 原生工资计时桌宠：白色电子时钟、猫猫头、每秒刷新的今日收入和月累计。C# WinForms / .NET Framework 4.x，无联网依赖。

点击主界面的猫猫头可互动：连续 1/2/3/4 次分别微笑、疑惑、小情绪、生气，最后一次点击两秒后恢复。四击时今日金额临时显示为 0，任务栏金额同步；实际工资、月累计和保存记录不变。生气期间重复点击不会延长两秒动画。

![主界面](docs/images/main.png)

## 功能

- 230 × 193 像素主界面，拖动、置顶、系统托盘及单实例恢复。
- 最小化显示任务栏右侧的实时金额条，双击恢复；原生任务栏标题也同步金额。金额条是贴在任务栏上的悬浮小窗，避开托盘图标与时钟。
- 固定东八区 UTC+8；固定天数或当月应出勤天数折算；单双休、午休及假期/请假/调休日历可配置。
- 工作日询问加班，确认后到起计时间开始计费；可结束计时、补录历史小时，同日餐补一次。
- 全勤奖独立计算：月底或逐日计入，首月比例、请假/迟到取消、按月资格和异常记录可配置。
- 自定义背景、每日明细、CSV 导出、可选开机启动。

## 编译与运行

在 Windows PowerShell 中，于仓库目录执行：

```powershell
./Build.ps1
./dist/SalaryClock.exe
```

需要 Windows 和 .NET Framework 4.x，编译脚本使用系统自带的 C# 编译器。应用为免安装程序；请保留生成的 EXE 和猫头图标。

首次运行使用示例参数，不含个人工资及加班记录。进入“设置”填写自己的底薪、入职日期、排班、加班和全勤规则。底薪与全勤奖分开累计；午休默认继续计薪。

## 使用

- 左上为本月累计，中间为今日收入；主界面不展示工资单价等参数。
- `−` 最小化，右侧金额条每秒更新，双击金额条恢复。
- `×` 默认收到托盘，双击猫头恢复，右键可完全退出。重复启动 EXE 恢复现有实例。
- 原生任务栏按钮文字是否直接显示由 Windows 合并按钮设置决定；程序不会自动修改系统任务栏设置。
- “设置 → 日历”登记请假，“设置 → 全勤”登记迟到。自动全勤资格只根据已录考勤判断，不读取公司的打卡记录。月底模式在月末下班时计入；首月比例使用所选计薪分母。
- 加班询问需要程序运行；重启恢复已保存的计时状态，每段最多计到当日午夜。
- 修改计薪规则会重算历史估算。加班补录与计时记录相加，避免重复录入。

金额为税前估算，不计算个税、社保、公积金及未录入的扣补款。

## 验证

```powershell
./scripts/Test.ps1
```

验证工资计算、午休、单双休、加班/餐补、全勤、持久化、金额条、按钮布局和跨进程窗口恢复。测试使用独立的虚构数据与配置文件，不覆盖真实设置。GitHub Actions 自动在 Windows 构建、验证并生成程序附件。

## 文件结构与本地数据

`src/` 为源码，`assets/` 为猫头图标，`scripts/` 为验证脚本。运行时配置、背景及工资记录保存在程序目录。

仓库不包含个人工资配置、加班记录、桌面快捷方式或本机路径；`.gitignore` 排除运行时数据和构建输出。请勿把自己的“计薪设置.json”提交到 GitHub。
